# T-Pot Credential Report

## Description
This repository contains a report generated from the extraction of T-Pot credentials, focusing on the most commonly encountered usernames and passwords used in automated attacks. It includes visual analysis in the form of charts and a detailed list of the captured credentials, intended for security studies and risk assessments.

## Contents
- `index.html` – The main report file with graphical representation of username and password usage in attacks.
- `extracted_credentials.txt` – A detailed list of the captured credentials.

## How to Use
1. Clone or download this repository.
2. Open the `index.html` file in a web browser to view the report.
3. Download the `extracted_credentials.txt` file for a detailed analysis of the captured credentials.

## Additional Installation
No additional installations are required to view the report. However, to manipulate the data, it is recommended to use a text editor or an integrated development environment (IDE).
